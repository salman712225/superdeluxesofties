# Super Deluxe — Website Asset Bundle

This bundle consolidates the supplied brand references into a website-ready asset library.

## Folder structure
- `01_Brand` — logo / core identity
- `02_Flavour_Campaign` — the supplied 10-flavour campaign posters
- `03_Product_Cutouts` — supplied product-focused food visuals
- `04_Campaign_Creatives` — launch, seasonal and promotional creatives
- `05_Menu_And_Pricing` — supplied menu/catalog/pricing references
- `06_Storefront_And_Real_World` — storefront / real-world brand proof
- `07_Character_And_Story` — Mr. Deluxe, comic/storytelling and exploded-view references

## File convention
- `*_ORIGINAL` = source-quality reference supplied in the conversation
- `*_WEB.jpg` = web-ready JPEG, max 1800px, quality 88

## Website design direction extracted from the references
- Brand personality: playful, indulgent, family-friendly, energetic.
- Strong visual device: oversized product photography + radial/radiating backgrounds.
- Core visual language: bold display typography, high contrast, rounded containers, flavour-specific colour systems.
- Trust cues visible in the supplied creatives: real milk / real ingredients messaging and the green milk-product seal.
- Mascot/character system: Mr. Deluxe is a useful storytelling asset rather than just a decorative logo.
- Product storytelling: exploded-view graphics can become a dedicated “What's inside” / signature creations section.

## Important implementation note
Use the original assets when visual fidelity is important. Use the WEB JPEGs for normal website delivery when a smaller payload is preferable. Product images with black backgrounds are preserved as supplied; do not assume they are transparent cutouts.
